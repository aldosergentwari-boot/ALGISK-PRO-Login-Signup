ALGISK PRO

This version adds the missing visual behavior from the supplied reference:
- The button area is larger/taller.
- A fixed center anchor remains in one place.
- A glowing/dashed tether always runs from that fixed anchor to the runaway button.
- A dashed "destination/ghost button" shows where the real button is going.
- The real button can move anywhere inside the larger box: left, right, up, down and every diagonal.
- The button can visibly tilt/lean as it escapes.
- The target marker follows the destination while the tether remains anchored at the center.
- When all required fields are valid, the runaway behavior stops and the button stays in the target position.
- Forgot? is below the password field.
- Login accepts email or username.
- Sign Up requires username, email, password and confirmation.

Open index.html in Chrome/Edge or VS Code Live Server.
